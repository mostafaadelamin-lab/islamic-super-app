## Display glyph map
Since Quran content 2.0.0 the map in `packages/shared-schemas/quran-render.json` is **empty**: the KFGQPC text (v18, now v22) is drawn with the Complex's own font, which draws every code point of that text (open tanween U+0657/U+065E/U+0656 included) as published. The end-of-ayah ornament is drawn by that font from Arabic-Indic digits, so no U+06DD is added.
Earlier versions (quranenc text + Amiri Quran font) substituted three tanween code points in the rendered string only; stored text was never changed.
